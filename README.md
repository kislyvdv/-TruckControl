# TruckControl Enterprise

Офлайн-first прототип приложения для управления грузовыми рейсами.

## Что есть
- Компания и роли: диспетчер, менеджер, водитель.
- Водители, тягачи, прицепы.
- Рейсы: номер, маршрут, километраж, груз, загрузка/выгрузка.
- Редактирование рейсов и записей автопарка.
- Ручной одометр и GPS-точка.
- Заправки и расходы рейса: **Дизель** и **AdBlue**, литры, стоимость, валюта, АЗС и привязка к конкретному рейсу.
- Редактирование расходов топлива.
- Маршрутные точки и таможни с редактированием.
- Документы рейса: CMR, инвойс, таможенные и прочие документы.
- При добавлении документа сразу доступен выбор **Галерея / Камера / Файл**. Фото можно выбрать из галереи или снять камерой; файл сохраняется локально в браузере.
- Редактирование типа и примечания документов.
- Поиск и фильтры.
- Отчёты CSV и печать в PDF.
- JSON backup/restore.
- Офлайн-хранилище localStorage.
- PWA, устанавливается на iPhone через Safari → Поделиться → На экран «Домой».

## Важно
Это готовый демонстрационный клиентский прототип. Для настоящей корпоративной синхронизации между телефонами нужен сервер/API, база данных и HTTPS. В этой сборке предусмотрен интерфейс подключения к серверу, но серверные данные не передаются автоматически.

Фото и документы в этой версии сохраняются локально в браузере. Для большого количества фотографий в дальнейшем лучше перенести файлы в серверное хранилище.

## Запуск
Откройте `index.html` через HTTPS-хостинг. Для PWA браузер должен работать по HTTPS (кроме localhost).
