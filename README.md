# TruckControl Enterprise

Офлайн-first прототип приложения для управления грузовыми рейсами.

## Что есть
- Компания и роли: диспетчер, менеджер, водитель.
- Водители, тягачи, прицепы.
- Рейсы: номер, маршрут, километраж, груз, загрузка/выгрузка.
- Ручной одометр и GPS-точка.
- Заправки: литры, стоимость, валюта, АЗС.
- Маршрутные точки и таможни.
- Документы рейса: CMR, инвойс, таможенные и прочие документы, фото/файл как имя или ссылка.
- Состояния рейса.
- Поиск и фильтры.
- Отчёты CSV и печать в PDF.
- JSON backup/restore.
- Офлайн-хранилище IndexedDB.
- PWA, устанавливается на iPhone через Safari → Поделиться → На экран «Домой».

## Важно
Это готовый демонстрационный клиентский прототип. Для настоящей корпоративной синхронизации между телефонами нужен сервер/API, база данных и HTTPS. В этой сборке предусмотрен интерфейс подключения к серверу, но серверные данные не передаются автоматически.

## Запуск
Откройте `index.html` через HTTPS-хостинг. Для PWA браузер должен работать по HTTPS (кроме localhost).
