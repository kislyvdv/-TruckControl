# TruckControl: серверная база

Серверная часть использует SQLite в постоянном Docker volume. API:

- `GET /api/health`
- `GET /api/state`
- `PUT /api/state`

Авторизация: заголовок `X-API-Key`. Для продакшена замените `change-this-key` на длинный секрет и используйте HTTPS.

## Запуск

```bash
docker compose up -d --build
```

После запуска API доступен на `http://SERVER:8080`.

Данные лежат в Docker volume `truckcontrol_data`, поэтому перезапуск контейнера их не удаляет.


Excel-отчёт: после каждой успешной синхронизации сервер автоматически обновляет `data/TruckControl_Отчёт.xlsx`. Файл содержит отдельные листы по рейсам, водителям, автопарку, топливу, расходам, ТО и сводку с формулами. Для генерации установите зависимости из requirements.txt.


## Доработки TruckControl v8

- При входе выбирается роль: водитель, менеджер или директор; имя и фамилия сохраняются в профиле.
- Завершённые рейсы переносятся в отдельный архив с сохранённым текстом отчёта.
- При настроенном сервере закрытый рейс и отчёт синхронизируются через `PUT /api/state`.
- Если сервер не настроен, приложение предлагает системное меню «Поделиться» (если браузер поддерживает Web Share API); иначе скачивает TXT-отчёт.
- В учёте топлива доступны дизель, AdBlue и антигель, каждый тип учитывается отдельно.

Важно: выбор роли и ФИО является выбором профиля, а не защищённой авторизацией с паролем. Публикация в социальную сеть не выполняется без участия пользователя: браузер открывает системное меню отправки, где пользователь выбирает приложение и подтверждает публикацию.
